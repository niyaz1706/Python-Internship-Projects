This is a Python-based YouTube Video Downloader project.
It allows users to:
- Download YouTube videos
- Enter video URL
- Choose destination folder
- Handle invalid links with error messages
- Python
- yt-dlp Library
1. Download YouTube Videos
2. Select Destination Folder
3. Error Handling for Invalid Links
1. Open terminal
2. Run the following command:
python main.py
3. Enter YouTube video URL
4. Enter destination folder path
- Download YouTube Video
- Save to Desktop Folder
